Calculs pré-PVsyst - Python

Outil Python pour la vérification pré-dimensionnement : compatibilité tension onduleur (Voc froid / Vmp chaud), ratio DC/AC et estimation productible avant simulation PVsyst.

Fonctionnalités :

  • Calcul P_champ (kWc)
  • Vérification Voc froid < Vmax onduleur
  • Vérification Vmp dans plage MPPT
  • Ratio DC/AC (norme 0.9-1.25)
  • Estimation E_jour / E_an avec PSH et PR
