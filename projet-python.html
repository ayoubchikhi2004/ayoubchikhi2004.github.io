Projet Python : Analyse Physique du ZnO

Analyse complète de l'oxyde de zinc (ZnO) : de la préparation des données jusqu'aux résultats.

1. Calcul de la taille d'échantillon

Formule : n = Z² * p(1-p) / e²
Z=1.96 (95% confiance), p=0.5, e=0.07
n = 196 → on a choisi n = 200 mesures

2. Composition chimique et distribution des éléments

M(Zn)=65.38 g/mol, M(O)=16.00 g/mol, M(ZnO)=81.38 g/mol
Zn = 80.34% , O = 19.66%

Distribution des éléments dans le spectre EDX : pic O Kα (0.52 keV) et pics Zn Lα (1.01 keV) + Kα (8.63 keV).

3. Code 1 : create_csv.py - Génération des données

import pandas as pd
import numpy as np
n=200
time=np.arange(n)
voltage=5+0.5*np.sin(time/10)+np.random.normal(0,0.1,n)
current=10+2*np.cos(time/15)+np.random.normal(0,0.5,n)
resistance=voltage/(current/1000)
temp=25+0.05*time+np.random.normal(0,0.5,n)
df=pd.DataFrame({'Time_s':time,'Voltage_V':voltage,'Current_mA':current,'Resistance_Ohm':resistance,'Temp_C':temp})
df.to_csv('ZnO_realistic.csv',index=False)
print("CSV créé avec 200 lignes")

4. Code 2 : RDX.py - Analyse

import pandas as pd

5. Code 3 : analyse_complete.py - Taille + Spectre

import math
import matplotlib.pyplot as plt
Z=1.96; p=0.5; e=0.07
n=math.ceil((Z**2*p*(1-p))/(e**2))
print(f"Taille calculée: n = {n}")

elements={'O (Kα: 0.52 keV)':19.66,'Zn (Lα: 1.01 keV)':25.0,'Zn (Kα: 8.63 keV)':55.34}
plt.bar(elements.keys(),elements.values(),color=['skyblue','orange','red'])
plt.title('Distribution des elements dans le spectre EDX (ZnO)')
plt.ylabel('Pourcentage massique (%)')
plt.tight_layout()
plt.savefig('spectre_elements.png')
