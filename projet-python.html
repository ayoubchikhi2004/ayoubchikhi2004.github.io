Analyse Python : ZnO non dopé

1. Spectre DRX - ZnO non dopé (002)

Code Python - Spectre DRX
import matplotlib.pyplot as plt
import numpy as np

theta = np.linspace(30, 38, 1000)
intensity = 50 + 1800*np.exp(-((theta-34.42)/0.15)**2) + np.random.normal(0,30,len(theta))

plt.figure(figsize=(10,6))
plt.plot(theta, intensity, color='black', linewidth=1.5)
plt.xlabel('2θ (degrés)')
plt.ylabel('Intensité (u.a.)')
plt.title('DRX - ZnO non dopé - Pic (002)')
plt.grid(True, alpha=0.3)
plt.savefig('spectre_zno_002.png', dpi=300, bbox_inches='tight')
plt.show()

3. Tension en fonction du temps

Code Python - Tension/Temps
import matplotlib.pyplot as plt
import numpy as np
t = np.linspace(0, 10, 500)
v = 5*np.sin(2*np.pi*0.5*t) + np.random.normal(0,0.2,len(t))
plt.figure(figsize=(10,5))
plt.plot(t, v)
plt.xlabel('Temps (s)')
plt.ylabel('Tension (V)')
plt.title('Tension en fonction du temps')
plt.grid(True)
plt.savefig('plot_voltage_time.png', dpi=300, bbox_inches='tight')
plt.show()

4. Résistance en fonction de la température

Code Python - Résistance/Température
import matplotlib.pyplot as plt
import numpy as np
temp = np.linspace(20, 200, 100)
R = 100 * np.exp(-0.01*(temp-20)) + np.random.normal(0,2,len(temp))
plt.figure(figsize=(10,5))
plt.plot(temp, R, color='red')
plt.xlabel('Température (°C)')
plt.ylabel('Résistance (Ω)')
plt.title('Résistance en fonction de la température')
plt.grid(True)
plt.savefig('plot_resistance_temp.png', dpi=300, bbox_inches='tight')
plt.show()
